# Stardew Encyclopedia

Русскоязычный статический справочник по Stardew Valley с фокусом на Android и iOS.

## Публикация на GitHub Pages

1. Загрузите **содержимое** этой папки в корень репозитория `stardew-encyclopedia`.
2. Убедитесь, что `index.html` находится в корне репозитория.
3. В GitHub откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохраните настройки и дождитесь публикации.

Сайт рассчитан на адрес проекта GitHub Pages вида:
`https://USERNAME.github.io/REPOSITORY/`

## Добавление статей

1. Добавьте JSON-массив в `data/objects/`.
2. Добавьте относительный путь к файлу в `data/manifest.json`.
3. Следуйте `docs/SCHEMA.md`.
4. Указывайте платформу и версию игры, на которых проверены данные.
5. Не добавляйте неподтверждённые игровые шансы.

## Локальная проверка

Страницы используют `fetch()` для загрузки JSON. Поэтому не открывайте `index.html` напрямую через `file://`. Запустите локальный статический сервер или используйте GitHub Pages.
