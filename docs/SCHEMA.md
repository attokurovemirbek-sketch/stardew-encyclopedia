
# Схема данных Stardew Encyclopedia

## Где хранятся статьи

Все игровые объекты хранятся в папке `data/objects/`.

Каждый JSON-файл должен содержать массив объектов.

Чтобы подключить новый файл, добавьте его путь в `data/manifest.json`.

## Структура объекта

Каждая статья может содержать следующие поля:

- `id` — уникальный идентификатор на английском языке.
- `name_ru` — русское название.
- `name_en` — английское название.
- `category` — ID категории из `data/categories.json`.
- `description` — описание.
- `image` — путь к изображению.
- `location` — места нахождения.
- `obtain` — условия получения.
- `prices` — цены.
- `rarity` — редкость.
- `probabilities` — вероятности.
- `related` — ID связанных объектов.
- `sources` — источники информации.
- `version` — версия игры.
- `platforms` — платформы, на которых проверены данные.
- `popular` — показывать ли статью среди популярных.
- `updated` — дата последней проверки.

## Вероятности

`probabilities[].value` — число от 0 до 1.

Пример: `0.25` означает 25%.

Всегда указывайте условия, при которых действует вероятность. Не выдавайте приблизительные оценки за точные шансы.

## Достоверность

Используйте следующие статусы:

- Подтверждено — проверено надёжным источником или повторяемым тестом.
- Наблюдение — замечено в игре, но пока не подтверждено.
- Требует проверки — информация спорная или непроверенная.

## Мобильные платформы

Энциклопедия предназначена для Android и iOS.

Не переносите автоматически данные из ПК-версии. Указывайте платформу и версию игры, на которой информация проверена.

## Источники

Каждая статья должна содержать ссылки на источники.

Не добавляйте выдуманные сведения, вероятности и характеристики.
